# iPhone & Apple Watch capture

SwiftUI sources for the offline-first voice recorder. They are not an Xcode project; follow [docs/ios-watch.md](../docs/ios-watch.md) to create one (about five minutes).

- `AssistantCapture/` — iPhone app (recorder, durable background upload queue, watch receiver, settings)
- `AssistantCaptureWatch/` — Apple Watch recorder that hands files to the phone
